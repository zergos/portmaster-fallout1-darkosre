# portmaster-fallout1-darkosre
Fallout 1 binary release for Portmaster (dArkOSRE)

Original build published on Portmaster: https://portmaster.games/detail.html?name=fallout1
Source code: https://github.com/alexbatalov/fallout1-ce

## Build sequence

1. Make sure Docker installed
2. Go to `docker` directory and run `build.sh`
3. Copy `docker/out/fallout-ce` to `fallout1-pm/fallout`
4. And don't forget to copy your original game data files (master, critter etc.)

Have fun :)
